# Sales Prediction Using Python

## Overview

This project predicts sales based on advertising expenditure on TV, Radio, and Newspaper platforms using Machine Learning.

## Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Scikit-Learn

## Machine Learning Model

* Linear Regression

## Results

* R² Score: 0.9059

## Features

* Data preprocessing
* Correlation heatmap
* Data visualization
* Sales prediction
* Model evaluation

## How to Run

1. Install required libraries:
   pip install pandas matplotlib seaborn scikit-learn

2. Run:
   python sales_prediction.py
